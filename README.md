# Patho-Bench-dl

This is a tool for downloading data required to run (Patho-Bench)[https://github.com/mahmoodlab/Patho-Bench]. 

Currently it will download:
- CPTAC datasets from The Cancer Imaging Archive (TCIA)
- Panda dataset from the kaggle competition prostate-cancer-grading-assessment

To download from kaggle, you need to make sure you have an api key via the environment variable or the kaggle.json file in ~/.config/kaggle/
